# Day 4: StrDataNum Assignment

## Assignment Overview

This comprehensive assignment combines **String Functions**, **Date Functions**, and **Number Functions** to demonstrate practical SQL skills in data manipulation and transformation.

## Assignment Requirements

This assignment tests your ability to:
- Manipulate and format strings
- Work with dates and timestamps
- Perform numeric calculations
- Combine multiple functions together
- Create complex queries using nested functions

## Scenario

You are working with a company database containing customer information. You need to:
1. Format and clean customer data
2. Calculate business metrics
3. Process dates for reporting
4. Create formatted reports combining all three function types

## Key Concepts Covered

- **String Functions**: UPPER, LOWER, CONCAT, SUBSTRING, REPLACE, TRIM, LENGTH
- **Date Functions**: YEAR, MONTH, DAY, DATEDIFF, DATE_ADD, DATE_FORMAT
- **Number Functions**: ROUND, CEIL, FLOOR, MOD, POWER, ABS

## Assignment Complexity

This assignment progresses from simple single-function queries to complex nested function calls that combine all three types of functions.

## Learning Outcomes

By completing this assignment, you will:
- Understand how to combine multiple functions in a single query
- Learn practical data transformation techniques
- Gain experience with real-world SQL scenarios
- Develop skills in data cleaning and formatting
