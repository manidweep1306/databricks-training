# Week 2: SQL Functions Mastery

## Overview

This week focuses on essential SQL functions for data manipulation and transformation:

| Day | Topic | Focus |
|-----|-------|-------|
| Day 1 | String Functions | text manipulation, formatting |
| Day 2 | Date Functions | date arithmetic, formatting |
| Day 3 | Number Functions | mathematical operations, rounding |
| Day 4 | StrDataNum Assignment | combining all three function types |
| Day 5 | Null Functions | handling missing data |
| Day 6 | REGEX | pattern matching and validation |

## Key Concepts

- **String Functions**: UPPER, LOWER, CONCAT, SUBSTRING, REPLACE, TRIM
- **Date Functions**: YEAR, MONTH, DAY, DATEDIFF, DATE_ADD, DATE_FORMAT
- **Number Functions**: ROUND, CEIL, FLOOR, ABS, MOD, POWER, SQRT
- **Null Handling**: COALESCE, IFNULL, IS NULL, CASE WHEN
- **REGEX**: Pattern matching for validation and extraction

## Skills Developed

✓ Text and data cleaning
✓ Date calculations and formatting
✓ Mathematical computations
✓ Null value handling
✓ Data validation using patterns
✓ Complex multi-function queries

Each day includes a README with theory and a queries.sql file with practice problems and solutions.
