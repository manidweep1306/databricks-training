# Day 3: Number Manipulation

## What You Learned

Number functions allow you to perform mathematical operations, rounding, and numeric transformations on data. These are essential for calculations, statistical analysis, and data normalization.

### Key Number Functions

1. **ROUND()** - Rounds a number to a specified number of decimal places
   - Syntax: `ROUND(number, decimal_places)`
   - Example: `ROUND(3.14159, 2)` returns `3.14`

2. **CEIL()** / **CEILING()** - Rounds up to the nearest integer
   - Syntax: `CEIL(number)`
   - Example: `CEIL(3.2)` returns `4`

3. **FLOOR()** - Rounds down to the nearest integer
   - Syntax: `FLOOR(number)`
   - Example: `FLOOR(3.8)` returns `3`

4. **ABS()** - Returns the absolute value (positive value)
   - Syntax: `ABS(number)`
   - Example: `ABS(-10)` returns `10`

5. **MOD()** - Returns the remainder after division
   - Syntax: `MOD(dividend, divisor)`
   - Example: `MOD(10, 3)` returns `1`

6. **POWER()** - Raises a number to a power
   - Syntax: `POWER(base, exponent)`
   - Example: `POWER(2, 3)` returns `8`

7. **SQRT()** - Returns the square root of a number
   - Syntax: `SQRT(number)`
   - Example: `SQRT(16)` returns `4`

8. **EXP()** - Returns e raised to the power of a number
   - Syntax: `EXP(number)`
   - Example: `EXP(1)` returns `2.718281828...`

9. **LN()** / **LOG()** - Returns the natural logarithm
   - Syntax: `LN(number)`
   - Example: `LN(2.718281828)` returns `1`

10. **LOG10()** - Returns the logarithm base 10
    - Syntax: `LOG10(number)`
    - Example: `LOG10(100)` returns `2`

11. **SIGN()** - Returns -1, 0, or 1 based on whether number is negative, zero, or positive
    - Syntax: `SIGN(number)`
    - Example: `SIGN(-5)` returns `-1`

12. **TRUNCATE()** - Truncates a number to a specified number of decimal places
    - Syntax: `TRUNCATE(number, decimal_places)`
    - Example: `TRUNCATE(3.14159, 2)` returns `3.14`

13. **GREATEST()** - Returns the greatest value among multiple values
    - Syntax: `GREATEST(value1, value2, value3, ...)`
    - Example: `GREATEST(5, 10, 3)` returns `10`

14. **LEAST()** - Returns the smallest value among multiple values
    - Syntax: `LEAST(value1, value2, value3, ...)`
    - Example: `LEAST(5, 10, 3)` returns `3`
